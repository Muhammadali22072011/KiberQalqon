- **Node 24 migration (2026-07-09, DONE + LIVE):** Vercel deprecates Node 20 after 2026-10-01. Migrated to 24. Required 3 changes together (any alone fails): (1) `package.json` `engines.node` → `"24.x"`; (2) `@vercel/node` devDep `^3.2.0`→`^5.8.22` AND `vercel.json` functions `runtime` `@vercel/node@3.2.0`→`@vercel/node@5.8.22` (3.x runtime rejects node 24 with "Found invalid Node.js Version: 24.x"); (3) **`"type": "module"` added to `package.json`** — THE critical fix: @vercel/node 5.x compiles functions to ESM (`import … from '../lib/x.js'`), but without `"type":"module"` the runtime `require()`s them as CJS → every function 500s (`FUNCTION_INVOCATION_FAILED`, whole API dead). Safe because the project has zero CJS files (all `.mjs`/`.ts`; scripts are `.mjs`, config is `vite.config.ts`). CI (`ci.yml`) also on node 24. Committed 431a56b. **Debug recipe if functions 500 after a runtime bump:** `vercel pull --yes` → `vercel build` → `node -e "import('./.vercel/output/functions/api/config.func/api/config.js')"` — a `MODULE_TYPELESS_PACKAGE_JSON` warning = the func package.json needs `"type":"module"`. Rollback is instant + reliable: `vercel rollback <last-good-deploy-url> --yes` (used it to restore prod mid-debug).
