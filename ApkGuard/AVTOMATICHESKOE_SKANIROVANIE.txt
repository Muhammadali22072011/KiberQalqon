🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ:

Функция autoScanAllApks():
1. Показывает "🔍 Qidirilmoqda..."
2. Ищет APK файлы (таймаут 3 сек)
3. Показывает "📊 Topildi: X ta APK"
4. Для каждого файла:
   - Показывает "🔍 Tekshirilmoqda: N/X"
   - Сканирует (таймаут 5 сек)
   - Если опасный - удаляет
   - Отправляет уведомление со звуком
5. Обновляет список
6. Показывает итог: "✅ Tekshirildi: X | Bloklandi: Y"
7. Отправляет итоговое уведомление

Уведомления:
- Два канала: "uzguard_danger" и "uzguard_safe"
- Опасные: HIGH priority + звук + вибрация
- Безопасные: DEFAULT priority + вибрация
- BigTextStyle для длинных сообщений
