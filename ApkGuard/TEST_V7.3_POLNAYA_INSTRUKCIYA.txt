═══════════════════════════════════════════════════════════

ШАГ 1: Подготовка
-----------------
1. Если KiberQalqon уже установлен - УДАЛИ его полностью
2. Скопируй app-debug.apk на телефон
3. Открой файл и установи

ШАГ 2: Первый запуск
--------------------
1. Открой KiberQalqon
2. ДОЛЖНО ПОЯВИТЬСЯ:
   ✓ Синий экран
   ✓ Белый логотип щита
   ✓ Текст "KIBERQALQON"
   ✓ Текст "Himoya zararli APK fayllardan"
   ✓ Внизу маленьким шрифтом "Version 7.3"
   ✓ Всё плавно появляется (анимация)

ШАГ 3: Запрос разрешения на файлы
----------------------------------
1. Через 1.5 секунды ДОЛЖЕН ПОЯВИТЬСЯ диалог:
   "Разрешение на доступ к файлам"
   "KiberQalqon нужен доступ ко всем файлам..."
   
2. Нажми "OK"

3. ДОЛЖНЫ ОТКРЫТЬСЯ настройки Android

4. Найди "KiberQalqon" в списке

5. Включи переключатель "Разрешить доступ"

6. Нажми "Назад"

ШАГ 4: Запрос разрешения на показ поверх окон
----------------------------------------------
1. ДОЛЖЕН ПОЯВИТЬСЯ диалог:
   "Разрешение на показ поверх других окон"
   "KiberQalqon нужно показывать предупреждения..."

3. ДОЛЖНЫ ОТКРЫТЬСЯ настройки Android

4. Найди "KiberQalqon" в списке

5. Включи переключатель "Разрешить показ поверх других приложений"

6. Нажми "Назад"

ШАГ 5: Главный экран
--------------------
1. ДОЛЖЕН ОТКРЫТЬСЯ главный экран KiberQalqon

2. Проверь что видно:
   ✓ Заголовок "KIBERQALQON"
   ✓ Переключатель "Фоновая защита"
   ✓ Кнопки: 🌐 (язык), 📊 (dashboard), ⚙️ (настройки)
   ✓ Текст "Topilgan APK: 0"

ШАГ 2: Скачай тестовый APK

1. В браузере открой любой сайт с APK файлами

   ✓ Результат проверки

------------------------
Если файл БЕЗОПАСНЫЙ:
✓ Зелёная карточка
✓ Текст "✓ XAVFSIZ"
✓ "Fayl ma'lum xavflarni o'z ichiga olmaydi"
✓ Окно закроется через 3 секунды

🐛 ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
═══════════════════════════════════════════════════════════

ПРОБЛЕМА 1: Окно предупреждения не появляется
----------------------------------------------
ПРИЧИНА: Нет разрешения на показ поверх окон
РЕШЕНИЕ:
1. Открой Настройки Android
2. Приложения → KiberQalqon
3. Дополнительно → Показ поверх других приложений
4. Включи

ПРОБЛЕМА 2: Не находит APK файлы
---------------------------------
ПРИЧИНА: Нет разрешения на чтение файлов
РЕШЕНИЕ:
1. Открой Настройки Android
2. Приложения → KiberQalqon
3. Разрешения → Файлы и медиа
4. Разреши доступ ко всем файлам

ПРОБЛЕМА 3: Приложение вылетает
--------------------------------
ПРИЧИНА: Ошибка в коде
РЕШЕНИЕ:
1. Открой логи: adb logcat | grep "KiberQalqon"
2. Найди ошибку
3. Сообщи мне

ПРОБЛЕМА 4: Splash Screen не показывается
------------------------------------------
ПРИЧИНА: Кеш старой версии
РЕШЕНИЕ:
1. Удали приложение полностью
2. Перезагрузи телефон
3. Установи заново
