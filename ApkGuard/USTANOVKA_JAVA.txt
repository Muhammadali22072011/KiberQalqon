  КАК УСТАНОВИТЬ JAVA ДЛЯ СБОРКИ ANDROID ПРИЛОЖЕНИЯ
═══════════════════════════════════════════════════════════════

ПРОБЛЕМА: У вас Java 8, а нужна Java 11 или выше (рекомендуется Java 17)

РЕШЕНИЕ:

1. Скачайте JDK 17 (Eclipse Temurin):
   https://adoptium.net/temurin/releases/?version=17
   
   Выберите:
   - Operating System: Windows
   - Architecture: x64 (если у вас 64-битная Windows)
   - Package Type: JDK
   - Нажмите кнопку скачивания .msi файла

2. Установите скачанный файл:
   - Запустите .msi файл
   - Следуйте инструкциям установщика
   - ✅ ВАЖНО: Поставьте галочку "Set JAVA_HOME variable"
   - ✅ ВАЖНО: Поставьте галочку "Add to PATH"

3. Перезапустите командную строку (закройте и откройте заново)

4. Проверьте установку:
   Откройте командную строку и введите:
   java -version
   
   Должно показать что-то вроде:
   openjdk version "17.0.x"

5. Теперь запустите снова:
   ZAPUSK_BEZ_ANDROID_STUDIO.bat

═══════════════════════════════════════════════════════════════

АЛЬТЕРНАТИВА: Если у вас уже установлена Android Studio

Если у вас установлена Android Studio, можно использовать её Java:

1. Найдите путь к Java в Android Studio:
   Обычно: C:\Program Files\Android\Android Studio\jbr

2. Установите переменную окружения JAVA_HOME:
   - Нажмите Win + Pause/Break (или Пуск → Параметры → Система → О системе)
   - Дополнительные параметры системы
   - Переменные среды
   - Создайте новую системную переменную:
     Имя: JAVA_HOME
     Значение: C:\Program Files\Android\Android Studio\jbr
   - Добавьте в PATH: %JAVA_HOME%\bin

3. Перезапустите командную строку и попробуйте снова
