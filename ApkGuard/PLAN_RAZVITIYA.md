#### 1.1 **WorkManager для надёжной фоновой проверки** ⭐⭐⭐
**Зачем:** FileObserver не всегда срабатывает, нужна периодическая проверка

**Что делать:**
- Добавить WorkManager в build.gradle
- Создать PeriodicCheckWorker.kt
- Проверка каждые 15 минут
- Даже если FileObserver не сработал - найдёт новые APK

**Код:**
```kotlin
class PeriodicCheckWorker(context: Context, params: WorkerParameters) : Worker(context, params) {
    override fun doWork(): Result {
        // Ищем новые APK
        val apks = FullPhoneScan.findAllApkFiles(applicationContext)
        
        // Проверяем каждый
        apks.forEach { apk ->
            val result = ApkScanner.scan(applicationContext, apk.path)
            if (result.verdict == ScanResult.Verdict.DANGER) {
                // Показываем окно
                showAlert(apk)
            }
        }
        
        return Result.success()
    }
}
```
