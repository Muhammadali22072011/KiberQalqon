🔧 ТЕХНИЧЕСКИЕ УЛУЧШЕНИЯ:

Асинхронность:
- scope.launch для всех долгих операций
- withContext(Dispatchers.IO) для файловых операций
- withContext(Dispatchers.Main) для UI обновлений
- delay(100) для отрисовки UI перед тяжёлыми операциями

Таймауты:
- 3 секунды на поиск файлов
- 5 секунд на сканирование
- 15-30 секунд на загрузку на сервер

Защита от сбоев:
- Try-catch на ВСЕХ операциях
- Проверка файлов перед использованием
- Блокировка кнопок во время работы
- Логирование всех ошибок

Оптимизации:
- Поиск только в Downloads
- Максимум 50 файлов
- Максимум 20 файлов в ZIP
- Чтение максимум 500KB
