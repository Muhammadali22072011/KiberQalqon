Используй этот промпт в DALL-E, Midjourney, Stable Diffusion или других AI генераторах изображений:

---

## 📱 Промпт на английском (для DALL-E / Midjourney):

```
Create a modern mobile app icon for "KiberQalqon" - an Android antivirus application.

Design requirements:
- Main element: Shield with a checkmark or Android robot inside
- Color scheme: Cyan/Turquoise (#00BCD4) gradient to Green (#4CAF50)
- Style: Flat design, Material Design 3, modern and clean
- Shape: Rounded square (adaptive icon for Android)
- Background: Gradient from cyan to green
- Icon should look professional and trustworthy
- Minimalist style, not too complex
- Should work well at small sizes (48x48px to 512x512px)

Additional elements (optional):
- Subtle circuit board pattern in background
- Glow effect around shield
- Small lock symbol
- Android green accent

Style references: Google Material Design, modern antivirus apps like Avast, Kaspersky
Output: High resolution, transparent background, PNG format
```

## 📐 Технические требования:

- **Размер:** 512x512px (минимум)
- **Формат:** PNG с прозрачным фоном
- **Цвета:** 
  - Основной: #00BCD4 (Cyan)
  - Акцент: #4CAF50 (Green)
  - Дополнительно: #FFFFFF (White)
- **Стиль:** Flat, Material Design 3
- **Форма:** Квадрат с закруглёнными углами (radius 20%)

## 📝 Пошаговая инструкция:

1. Выбери генератор (рекомендую DALL-E 3 или Bing)
2. Скопируй промпт на английском
3. Вставь в генератор
4. Если результат не понравился - добавь детали:
   - "make it more minimalist"
   - "add more gradient"
   - "make shield bigger"
   - "simplify the design"
5. Скачай PNG в высоком разрешении
6. Сохрани как `ic_launcher.png`
