🔐 РАЗРЕШЕНИЯ:
--------------

1. MANAGE_EXTERNAL_STORAGE (Android 11+):
   - Доступ ко всем файлам
   - Нужен для поиска APK везде
   - Запрашивается через Settings

2. READ_EXTERNAL_STORAGE (Android 10-):
   - Чтение внешнего хранилища
   - Запрашивается через ActivityCompat

3. READ_MEDIA_* (Android 13+):
   - Чтение медиа файлов
   - Запрашивается через ActivityCompat

4. SYSTEM_ALERT_WINDOW:
   - Показ поверх других окон
   - Нужен для предупреждений
   - Запрашивается через Settings

🚨 AUTOSCANACTIVITY:
--------------------

Флаги окна:
- FLAG_SHOW_WHEN_LOCKED - показ на заблокированном экране

- FLAG_TURN_SCREEN_ON - включение экрана
- FLAG_KEEP_SCREEN_ON - не гаснет
- FLAG_FULLSCREEN - полный экран

Manifest:
- exported="true" - можно запускать извне
- launchMode="singleTop" - одно окно
- showWhenLocked="true" - показ на блокировке
- turnScreenOn="true" - включение экрана
- excludeFromRecents="true" - не в списке задач
- taskAffinity="" - отдельная задача
