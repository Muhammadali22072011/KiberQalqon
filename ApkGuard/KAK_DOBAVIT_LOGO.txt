🎯 СПОСОБ 2: ПРАВИЛЬНЫЙ (Разные размеры)

Используй Android Asset Studio:
https://romannurik.github.io/AndroidAssetStudio/icons-launcher.html

1. Открой сайт
2. Загрузи logo.png
3. Настрой:
   - Padding: 10%
   - Shape: Square
   - Background: Transparent
4. Скачай ZIP
5. Распакуй в KiberQalqon/app/src/main/res/

🎯 СПОСОБ 3: ВРУЧНУЮ (Если умеешь Photoshop)

Создай разные размеры:
- mipmap-mdpi: 48x48px
- mipmap-hdpi: 72x72px
- mipmap-xhdpi: 96x96px
- mipmap-xxhdpi: 144x144px
- mipmap-xxxhdpi: 192x192px

Сохрани как ic_launcher.png в каждую папку.

2) Почему “окно сканирования не всегда появляется”: это часто не FileObserver

На Android 10+ есть жёсткие ограничения на запуск Activity из фона. Даже если FileObserver сработал, startActivity() может быть заблокирован/проигнорирован. Поэтому “не появляется полноэкранка” часто лечится так:

✅ Вместо прямого startActivity из фона → показываем уведомление высокого приоритета с fullScreenIntent (или хотя бы heads-up). Это надёжнее.

3.1 Улучшаем FileObserver (дребезг, переименование, “файл ещё пишется”)

Браузеры часто пишут во временный файл, потом переименовывают/перемещают — из-за этого событие может быть не “CREATE”, а “MOVED_TO”, и ещё файл может быть 0 байт до завершения записи. Плюс FileObserver реально бывает нестабильным на части устройств/версий. (Stack Overflow)

class ApkFileObserver(     private val watchDir: File,     private val scope: CoroutineScope,     private val onApkReady: (File) -> Unit ) : FileObserver(     watchDir.absolutePath,     CREATE or MOVED_TO or CLOSE_WRITE ) {     private val events = MutableSharedFlow<File>(extraBufferCapacity = 128)      init {         scope.launch(Dispatchers.IO) {             events                 .filter { it.extension.equals("apk", ignoreCase = true) }                 .debounce(700) // собираем события CREATE/MOVED_TO/CLOSE_WRITE                 .collect { file ->                     if (waitUntilStable(file)) onApkReady(file)                 }         }     }      override fun onEvent(event: Int, path: String?) {         if (path.isNullOrBlank()) return         val f = File(watchDir, path)         events.tryEmit(f)     }      private suspend fun waitUntilStable(file: File): Boolean {         if (!file.exists()) return false         var last = -1L         repeat(8) {             val len = file.length()             if (len > 0 && len == last) return true             last = len             delay(250)         }         return file.length() > 0     } }

6) Производительность: убираем лаги

Главные правила

Никакого “по всему телефону” без необходимости — это и медленно, и на новых Android часто невозможно без “All files access”.

Сканируй только целевые места:

Downloads (через MediaStore/SAF)

выбранные пользователем папки (SAF folder picker)

каталоги мессенджеров — если есть доступ (иначе periodic scan через доступные URI)

Кэшируй результат: (path, size, lastModified) → ScanResult. Если файл не менялся — не пересканируй.

Мини-кэш (Room):

@Entity(tableName = "scan_cache") data class ScanCache(     @PrimaryKey val key: String, // например: uri.toString() или абсолютный путь     val size: Long,     val lastModified: Long,     val verdict: Int,     val score: Int,     val scannedAt: Long ) 

И логика:

перед сканом смотри кэш
