🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ:

FileObserver теперь:

1. Принимает File вместо String:
   ```kotlin
   ApkFileObserver(applicationContext, downloadDir)
   ```

2. Логирует ВСЕ события:
   - "File event: [event], path: [path]"
   - "New APK detected: [name]"
   - "File exists, size: [size]"
   - "Launching auto scan for: [name]"
   - "AutoScanActivity started successfully"

3. Увеличена задержка:
   - Было: 1 секунда
   - Стало: 2 секунды
   - Причина: файл должен полностью скачаться

4. Проверки:
   - Проверка существования файла
   - Проверка размера файла (> 0)
   - Try-catch на всех уровнях

5. Toast при запуске:
   - "FileObserver запущен" - успешно
   - "Ошибка FileObserver: [сообщение]" - ошибка

🔍 ЛОГИ ДЛЯ ОТЛАДКИ:

Если окно не выскакивает, смотри логи:

```
adb logcat | grep ApkFileObserver
```

Должны быть:
- "File event: [event], path: [name].apk"
- "New APK detected: [name].apk"
- "File exists, size: [size]"
- "Launching auto scan for: [name].apk"
- "AutoScanActivity started successfully"

Если нет этих логов - FileObserver не работает.
Если есть - проверь разрешение SYSTEM_ALERT_WINDOW.
