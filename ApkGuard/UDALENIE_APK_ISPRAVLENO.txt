Проблема: KiberQalqon НЕ УДАЛЯЛ опасные APK файлы

Причина: На Android 10+ нельзя просто удалить файл из Downloads 
         через file.delete() - нужен MediaStore API

Решение: Добавлен метод deleteViaMediaStore() который:
         1. Ищет файл в MediaStore.Downloads
         2. Получает URI файла
         3. Удаляет через contentResolver.delete()
         4. Если не нашёл - пробует обычное удаление


✅ КАК РАБОТАЕТ:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Android 10+ (Q и выше):
  → Использует MediaStore API
  → Ищет файл по имени в Downloads
  → Удаляет через ContentResolver
  → Работает БЕЗ дополнительных разрешений!

Android 9 и ниже:
  → Обычное file.delete()
  → Работает с разрешением WRITE_EXTERNAL_STORAGE
