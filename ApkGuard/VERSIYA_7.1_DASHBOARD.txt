🚀 КАК ИСПОЛЬЗОВАТЬ:
--------------------
1. Открой UzGuard
2. Нажми кнопку 📊 в правом верхнем углу
3. Увидишь Dashboard с графиками
4. Спидометр показывает уровень защиты:
   - 80-100% = ЗАЩИЩЁН (зелёный)
   - 50-79% = СРЕДНИЙ (жёлтый)
   - 0-49% = ОПАСНО (красный)

📊 РАСЧЁТ УРОВНЯ ЗАЩИТЫ:
------------------------
Базовый уровень: 50%
+ 30% если фоновая защита включена
+ 10% если есть проверки за неделю
+ 10% если мало вирусов (< 10%)
= Итого: 0-100%

💾 СТАТИСТИКА:
--------------
- Автоматически сохраняется после каждой проверки
- График показывает проверки за последние 7 дней
- Счётчики обновляются в реальном времени
- Данные хранятся в SharedPreferences

🎨 АНИМАЦИИ:
------------
- Спидометр плавно заполняется (1.5 секунды)
- График появляется с анимацией (1 секунда)
- Цвета меняются в зависимости от уровня
- Плавные переходы между экранами
