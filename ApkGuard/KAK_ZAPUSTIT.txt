  КАК ЗАПУСТИТЬ UZGUARD И ПОСМОТРЕТЬ, КАК ВЫГЛЯДИТ ПРОГРАММА
═══════════════════════════════════════════════════════════════

1. Установите Android Studio (если ещё нет):
   https://developer.android.com/studio

2. Откройте проект в Android Studio:
   • Запустите Android Studio
   • File → Open
   • Выберите папку UzGuard (она внутри папки «апк вирус тахлил»)
   • Нажмите OK
   • Дождитесь синхронизации Gradle (первый раз может занять несколько минут)

3. Запустите приложение:
   • Подключите телефон по USB (включите «Отладка по USB» в настройках)
     ИЛИ запустите эмулятор: Tools → Device Manager → Create Device → запустить
   • В Android Studio нажмите зелёную кнопку Run (▶️) или Shift+F10
   • Выберите устройство (телефон или эмулятор)
   • Приложение установится и откроется — вы увидите интерфейс

4. Что вы увидите:
   • Верх: название «UzGuard», подзаголовок, кнопки языка (🌐) и настроек (⚙️)
   • Карточка «Фоновая защита» с переключателем
   • Кнопка «Найти и проверить APK»
   • Список найденных APK-файлов (если есть) с кнопкой «Проверить» у каждого
   • В Настройках: URL сервера, отправка на сервер, блокировка фишинговых уведомлений

Если папка UzGuard открыта в проводнике — запустите Otkrity_v_Android_Studio.bat:
он откроет проект в Android Studio по короткому пути (без кириллицы), чтобы не было
ошибки «Invalid path».

Если ошибка «Invalid path» или «Cannot Execute Command» всё равно появляется:
скопируйте папку UzGuard на рабочий стол в папку с латинским именем, например
C:\Users\Muhammadali\Desktop\UzGuard_proekt, и откройте в Android Studio уже её
(File → Open → выберите UzGuard_proekt).
