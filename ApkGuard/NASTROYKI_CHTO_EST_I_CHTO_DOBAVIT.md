# 🎛️ НАСТРОЙКИ KIBERQALQON

## ✅ ЧТО ЕСТЬ СЕЙЧАС:

### 1. **URL сервера** (Server URL)
   - Поле ввода для адреса сервера
   - Для загрузки APK на удалённый сервер для анализа
   - Подсказка: "http://example.com/api/upload"

### 2. **Загрузка на сервер** (Upload to Server)
   - Переключатель ВКЛ/ВЫКЛ
   - Автоматически отправлять подозрительные APK на сервер
   - Подсказка: "Отправлять подозрительные файлы на сервер для глубокого анализа"

### 3. **Блокировщик фишинга** (Phishing Blocker)
   - Переключатель ВКЛ/ВЫКЛ
   - Блокировать фишинговые уведомления
   - Подсказка: "Блокировать подозрительные уведомления от приложений"
   - Кнопка: "Включить доступ к уведомлениям"

### 4. **Кнопка "Сохранить"**
   - Сохраняет все настройки

---

## 🆕 ЧТО МОЖНО ДОБАВИТЬ:

### 🔥 ВАЖНЫЕ НАСТРОЙКИ:

#### 1. **Автоматическое удаление** ⭐⭐⭐
   - Переключатель: Автоматически удалять опасные APK
   - Варианты:
     - Удалять сразу (текущее поведение)
     - Спрашивать перед удалением
     - Только предупреждать (не удалять)

#### 2. **Уровень чувствительности** ⭐⭐⭐
   - Ползунок или выбор:
     - 🟢 Низкий (только явные вирусы)
     - 🟡 Средний (рекомендуется)
     - 🔴 Высокий (блокировать всё подозрительное)

#### 3. **Звук и вибрация** ⭐⭐
   - Включить звук при обнаружении вируса
   - Включить вибрацию
   - Выбор звука уведомления

#### 4. **Белый список** (Whitelist) ⭐⭐⭐
   - Список доверенных приложений
   - Не проверять APK от этих разработчиков
   - Кнопка "Добавить в белый список"

#### 5. **Чёрный список** (Blacklist) ⭐⭐
   - Список заблокированных разработчиков
   - Автоматически блокировать их APK

#### 6. **Папки для сканирования** ⭐⭐
   - Выбрать какие папки сканировать
   - Чекбоксы:
     - ✅ Downloads
     - ✅ Telegram
     - ✅ WhatsApp
     - ✅ Bluetooth
     - ✅ Весь телефон (медленно)

#### 7. **Расписание сканирования** ⭐
   - Автоматическое сканирование по расписанию
   - Выбор времени: Ежедневно в 02:00
   - Только при зарядке
   - Только при Wi-Fi

#### 8. **Обновление баз** ⭐⭐⭐
   - Автоматически обновлять базу вирусов
   - Частота обновления:
     - Ежедневно
     - Еженедельно
     - Вручную
   - Кнопка "Обновить сейчас"
   - Показать дату последнего обновления

#### 9. **Статистика** ⭐⭐⭐
   - Показать статистику:
     - Всего проверено: 156 APK
     - Заблокировано: 12 вирусов
     - Последняя проверка: 5 минут назад
   - Кнопка "Очистить статистику"

#### 10. **Экспорт/Импорт настроек** ⭐
   - Сохранить настройки в файл
   - Загрузить настройки из файла
   - Сброс к заводским настройкам

### 📊 ДОПОЛНИТЕЛЬНЫЕ ФУНКЦИИ:

#### 17. **История сканирований** ⭐⭐⭐
   - Список всех проверенных APK
   - Дата, время, результат
   - Кнопка "Очистить историю"

#### 18. **Карантин** ⭐⭐
   - Папка для подозрительных файлов
   - Вместо удаления - переместить в карантин
   - Можно восстановить или удалить навсегда

#### 19. **Облачное сканирование** ⭐⭐⭐
   - Отправлять хеш файла в облако
   - Проверять по базе VirusTotal
   - Требует интернет

#### 20. **Уведомления** ⭐⭐
   - Показывать уведомления о результатах
   - Ежедневный отчёт
   - Уведомление при обнаружении вируса
